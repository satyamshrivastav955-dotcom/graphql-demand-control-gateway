# Code of conduct

Be respectful and constructive. Assume good faith, critique code and ideas rather than people, and welcome newcomers.
Harassment, discrimination, personal attacks and publishing others' private information are not acceptable anywhere in
this project's issues, pull requests or discussions.

Maintainers may edit or remove contributions and restrict participation to protect these norms. To report a problem,
contact the maintainer through the GitHub profile linked in the README.

This statement is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
